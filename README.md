# The Moody Foundation — A Year in Review

Huston-Tillotson University's 2025–2026 report to The Moody Foundation, presented as an
interactive web report. Built for the University by
[Taylormade Creative](https://www.taylormadecreative.net).

## Structure

```
index.html    the complete report, self-contained
og-image.png  social share card
favicon.png   browser icon
```

## Credits

Colors, marks, and the mosaic pattern follow the Huston-Tillotson University Brand
Identity System. Every figure, date, and name on the page is taken from the
2025–2026 Report to The Moody Foundation prepared by the University.
