# The Moody Foundation — A Year in Review

Huston-Tillotson University's 2025–2026 report to The Moody Foundation, presented as an interactive
web report.

## Status: preview, not approved for release

The figures in this report are drawn from a draft document still under review by the University, so the
page carries `noindex` plus a blanket `robots.txt`. Remove both only after HT signs off.

## Structure

```
index.html    the complete report, self-contained
```

Everything is inlined — the animation library, the University marks, and the mosaic pattern — so the
page has no dependencies and no external requests apart from Google Fonts.

## Brand

Colour, marks, and supporting graphics follow the Huston-Tillotson University Brand Identity System.
The report uses the academic wordmark rather than the HT Rams athletic identity.

Typography note: the brand book specifies Martina Plantijn and Cards, neither of which is licensed
here, so the page uses Source Serif 4 and Archivo as stand-ins. Swap them in `:root` if HT provides the
licensed families.
